# `manhattan_distance()`

Part of **Stylometry** (`qhchina.analytics.stylometry.manhattan_distance`).

[View source](https://github.com/mcjkurz/qhchina/blob/main/qhchina/analytics/stylometry.py#L99)

Compute Manhattan (L1) distance between two vectors.

**Parameters:**
- `vec_a` (np.ndarray): First feature vector.
- `vec_b` (np.ndarray): Second feature vector.

**Returns:**
(float) Sum of absolute differences between corresponding elements.


**Example:**
```python
import numpy as np
from qhchina.analytics.stylometry import manhattan_distance

result = manhattan_distance(vec_a=np.array([0.6, 0.2, 0.4]), vec_b=np.array([0.6, 0.2, 0.4]))
```
