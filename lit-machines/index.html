Set up your AI coding agent

Accounts, a repository, and an agent connected to a language model. About fifteen minutes.

Last updated: Oct 2, 2026

Two things to choose

The assistant (the “harness”) is the app you talk to. It reads your files, writes code and runs it. Here we use VS Code with GitHub Copilot; OpenCode (a terminal app, or a desktop app) is an equivalent alternative.

The model does the thinking and runs on someone else’s servers. We bring our own API key for OpenRouter and use the model GLM-5.3-Flash. The assistant is only the messenger; the key connects the two.

You can change either one later without the other.

Where do you work? On a school or public computer, use GitHub Codespaces (in the browser). Such machines usually do not let you install Python, Git or VS Code, and everything a Codespace needs is already inside it. On your own computer you can choose freely.

Step 1 · Accounts and a repository

  1. A GitHub account. Register at github.com with a personal email, not a school address that expires after you leave. Your work lives here.
  2. An API key. Get yours at keyreg.qhchina.org. It allows you to use the external provider (OpenRouter). Keep it private: never paste it into your repository or share it.
  3. Your own copy of the template. Open github.com/mcjkurz/qh-starter, press the green Use this template button, and create your own repository. Do not edit the template itself.

Worth doing: apply for GitHub Education with your university email. Verified students get up to 180 Codespaces core-hours a month, far more than the free allowance.

Step 2 · Start the agent

In the browser: GitHub Codespaces

A Codespace is a computer that runs on GitHub’s servers and that you use through your browser. Nothing is installed on the machine in front of you, and Python and Git are already set up inside it. This is the right choice for school computers, and works just as well on your own.

  1. Open your new repository → green Code button → Codespaces → Create codespace on main. The first start takes a few minutes.
  2. Click the chat icon near the top of the window to open the Chat panel. It is already signed in with your GitHub account.
  3. Click the model picker at the bottom of the chat box → Other Models.
  4. Settings (gear) icon → Add Models → OpenRouter → paste your key.
  5. Pick GLM-5.3-Flash in the model picker. You are ready.

On your own computer: VS Code + Copilot

  1. Install VS Code from code.visualstudio.com/Download. On Windows, the standard System Installer is fine. On a Mac, open the .dmg and drag Visual Studio Code into Applications.
  2. Get your repository onto your computer: on the GitHub repository page press the green Code button, copy the address, and run git clone <address> in a terminal. Or press Download ZIP and unzip it. In VS Code, choose File → Open Folder and open that folder.
  3. Activate Copilot (first time only). Click the chat icon near the top of the window. If you do not see it, open the Extensions view (the square-icon button in the left sidebar), search for GitHub Copilot Chat and click Install. Then click Sign in to GitHub in the Chat panel and follow the prompts in your browser. No paid subscription is needed, because your OpenRouter key pays for the model.
  4. Add your key: model picker at the bottom of the chat box → Other Models → gear icon → Add Models → OpenRouter → paste your key.
  5. Pick GLM-5.3-Flash in the model picker.

The first run may complain about missing Python packages. Just ask the agent to install them for you.

Alternative: OpenCode

OpenCode works with almost any model provider. In a terminal (in Codespaces the template already has it installed):

  1. Type opencode and press Enter.
  2. Type /connect, select OpenRouter and paste your key.
  3. Type /models and select GLM-5.3-Flash.

On your own computer, install it from opencode.ai/download. On Windows, use the desktop app: installing OpenCode in a Windows terminal is a pain. If a terminal says command not found right after installing, open a new terminal; the old one has not noticed the install yet.

When you finish: commit and push your work (you can ask the agent to do it for you), then delete your Codespace at github.com/codespaces (… → Delete). Anything you did not push is lost when it is deleted, and an idle Codespace keeps using up your monthly hours.
