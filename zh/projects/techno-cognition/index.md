# 技術、認知與敘事體驗

<span class="en-title">Techno-Cognition and Narrative Experience</span>

本項目把文學讀作文本形式、具身認知、歷史中介與計算建模之間的互動。我們不把數字方法當作施加於固定對象之上的工具，而是追問神經、語言與算法模型，如何照亮文學意義生成與接受的分層過程。核心主張是理論性的：敘事經驗跨越多重時間與認知尺度，從局部的感官與情感信號，一路延伸到宏觀的文化闡釋結構。
