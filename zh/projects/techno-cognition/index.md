# 技術、認知與敘事體驗

<span class="en-title">Techno-Cognition and Narrative Experience</span>

敘事經驗是層層疊加、跨越多重時間尺度的認知歷程：從字音與詞語的瞬間感知，到情節與意義在記憶中逐步累積成形。本項目把這一歷程讀作文本形式、具身認知與歷史語境之間的互動。我們不把數字方法當作施加於固定對象之上的工具，而是追問神經、語言與算法模型，如何照亮意義生成與接受的分層過程。
