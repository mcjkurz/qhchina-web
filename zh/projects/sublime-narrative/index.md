# 敘事技術與崇高形象

<span class="en-title">The Sublime as a Narrative Technology</span>

崇高可以被理解為一種敘事技術：一種將運動、邊界與情感組織為尺度體驗的固定程式。在現代中國小說中，這一技術通過累積描寫強大自然現象的詞彙，並使之與情節特有的術語同步，直至敘事抵達跨越或釋放的時刻。計算批評有助於發現這些分散的模式，但核心主張是美學與認知層面的：崇高體驗產生於語言、身體與敘事形式的適時協調。
