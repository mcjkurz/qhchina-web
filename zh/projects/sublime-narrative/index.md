# 敘事技術與崇高形象

<span class="en-title">The Sublime as a Narrative Technology</span>

崇高可以被讀作一種敘事技術，一種把運動、邊界與情感組織成尺度體驗的固定程式。在現代中國小說中，這門技術累積描寫強大自然現象的詞彙，讓它們與情節專屬的術語同步，直到敘事抵達跨越或釋放的那一刻。計算批評有助於找出這些分散的模式，但真正的論點在美學與認知層面：崇高的體驗，來自語言、身體與敘事形式的適時協調。
