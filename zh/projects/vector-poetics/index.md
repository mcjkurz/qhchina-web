# 向量詩學

<span class="en-title">Vector Poetics</span>

對仗不只是律詩的形式規則，也是在概念空間中發現與創造秩序的方式。成對的詩句在句法、語義、聲調與節奏上彼此對齊，顯露看似遙遠的經驗領域之間潛藏的對稱。結合傳統詩學與語言模型，我們想知道：文學形式如何安排比較，尺度如何影響闡釋，而向量表示又如何讓對仗思維的結構現形。
