# 向量詩學

<span class="en-title">Vector Poetics</span>

對仗不只是律詩的形式規則，更是在概念空間裡發現與創造秩序的方式。成對的詩句在句法、語義、聲調與節奏上彼此對齊，讓看似遙遠的經驗領域顯露出潛藏的對稱。結合傳統詩學與語言模型，我們追問：詩的形式如何安排比較，尺度如何影響闡釋，向量表示又如何讓對仗思維的幾何結構顯現出來。
