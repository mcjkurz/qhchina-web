# 向量詩學

<span class="en-title">Vector Poetics</span>

對仗不僅是中國格律詩的形式規則，更是在概念空間中發現並創造秩序的方式。本項目將成對的詩句視為認知幾何的實驗：句法、語義、聲調與節奏彼此對齊，從而揭示看似遙遠的經驗領域之間潛在的對稱。結合傳統詩學與語言模型分析，本項目探問文學形式如何組織比較、尺度如何塑造闡釋，以及向量表示如何使對仗思維的概念結構變得可見。
