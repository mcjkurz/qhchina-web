# 具身認知與計量文體學

<span class="en-title">Cognitive Stylometry</span>

<img src="{{ site.baseurl }}/projects/cognitive-stylometry/maospeak_pattern.png" alt="具身認知與計量文體學" style="max-width: 80%; height: auto; margin: 2rem auto; display: block;">

本項目始於這樣一個觀念：文體是對期待與驚奇之間關係的管理。語言模型學到的是：在給定的語境下，哪些詞語和短語更可能接續出現。因此，它的預測誤差與不確定性，正好可以拿來為具有歷史情境的閱讀習慣建模。本項目以困惑度（perplexity）研究話語如何約束或拓展想像：宣傳靠重複既定的、被認可的模式來降低不確定性，文學則靠開闢多條有意義的語言路徑，讓感知煥然一新。
