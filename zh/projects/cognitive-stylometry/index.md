# 認知文體學

<img src="{{ site.baseurl }}/projects/cognitive-stylometry/maospeak_pattern.png" alt="認知文體學" style="max-width: 80%; height: auto; margin: 2rem auto; display: block;">

認知文體學始於這樣一個觀念：文體是對期待與驚奇之間關係的管理。語言模型學習在給定語境下哪些詞語和短語可能接續，因此它們的錯誤與不確定性可以用來為具有歷史情境的閱讀習慣建模。本項目以困惑度（perplexity）研究話語如何約束或拓展想像：宣傳通過重複被認可的模式來降低不確定性，而文學則通過開闢多條有意義的語言路徑來更新感知。
