# 技術認知論

技術認知論是一種研究文學的框架，將文學視為文本形式、具身認知、歷史中介與計算建模之間的互動。本項目不把數字方法看作施加於穩定對象之上的外部工具，而是追問神經、語言與算法模型如何闡明文學意義得以生產和接受的分層過程。其核心主張是理論性的：敘事經驗跨越多重時間與認知尺度展開，從局部的感官與情感信號，到宏大的文化闡釋結構。
